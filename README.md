# Financer - Telegram Bot для учета инвестиций

Telegram-бот для личного учета пассивного инвестиционного портфеля с автоматическим парсингом брокерских отчетов ВТБ.

## Возможности

- 📊 Загрузка и парсинг XLSX отчетов ВТБ
- 💾 Автоматическое сохранение снапшотов портфеля по месяцам
- 📈 Просмотр состава портфеля и общей стоимости
- 🎯 Расчет плана покупок для достижения целевого распределения 60/40

## Быстрый старт

### 1. Поднять БД

```bash
# Запустить Postgres в Podman/Docker
podman-compose up -d

# Или через docker-compose
docker-compose up -d
```

### 2. Применить миграции

```bash
# Подключиться к БД и выполнить миграцию
psql postgres://invest:invest@localhost:5432/invest < migrations/0001_init.sql
```

### 3. Настроить переменные окружения

Убедитесь, что в `.env` файле указаны:
```bash
BOT_TOKEN=your_telegram_bot_token
DATABASE_URL=postgres://invest:invest@localhost:5432/invest?sslmode=disable
RAW_DATA_DIR=./data
```

### 4. Запустить бота

```bash
go run cmd/bot/main.go
```

## Как это работает

### Шаг 1: Загрузка файла
1. Пользователь отправляет XLSX файл боту
2. Бот скачивает файл и сохраняет в `RAW_DATA_DIR`
3. Создается запись в таблице `upload` со статусом `RECEIVED`
4. Сохраняется метаинформация в `raw_file` (SHA256, путь)

### Шаг 2: Парсинг (воркер)
1. Воркер каждые 5 секунд проверяет файлы со статусом `RECEIVED`
2. Парсит XLSX файл, извлекая:
   - Общую стоимость портфеля
   - Остаток денежных средств
   - Список позиций (ISIN, название, количество, цена, стоимость)
3. Сохраняет данные в таблицы:
   - `valuation_snapshot` - общая сумма за месяц
   - `position_snapshot` - состав портфеля за месяц
4. Обновляет статус upload на `DONE`

### Шаг 3: Отображение
1. Команда `/ui` открывает интерактивное меню
2. Данные читаются из снапшотов через `PortfolioRepo`
3. Можно просматривать:
   - Список портфелей
   - Общую стоимость по месяцам
   - Детальный состав позиций

## База данных

### Основные таблицы

- `upload` - факт загрузки файла
- `raw_file` - метаданные сохраненного файла
- `account` - брокерские счета
- `valuation_snapshot` - общая оценка портфеля за период
- `position_snapshot` - позиции в портфеле за период
